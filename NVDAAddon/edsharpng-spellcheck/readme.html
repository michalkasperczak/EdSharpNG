EdSharpNG: spelling errors

This NVDA add-on announces spelling mistakes while you read and edit a document in EdSharpNG. It uses the Windows Spell Checking API, so it works in whatever language your Windows spell checker is set to, and needs no dictionary of its own.

What it does

As the cursor moves through the editor, a misspelled word is reported the way NVDA reports one in Microsoft Word: you hear that the word is misspelled as you reach it, instead of having to run a separate spell-check pass to find out.

Requirements

  • NVDA 2019.3 or later.
  • EdSharpNG.
  • A Windows spell-check language installed for the language you write in.

Installation

Open the file EdSharpNG-spellcheck.nvda-addon from the EdSharpNG program folder and confirm the installation in NVDA. The EdSharpNG installer can do this step for you.

Where to report a problem

Use Report a Problem in the Help menu of EdSharpNG (Alt+Shift+F1), or open an issue at github.com/michalkasperczak/EdSharpNG/issues.
