# Exercise 01 — document and save

**Goal.** Create a separate Markdown file and verify saving under your own name.

## Steps

Open a new document and type these three lines:

```text
# My first document
First sentence.
Second sentence.
```

Save it with `Ctrl+Shift+S` as `exercise-01.md` in a new exercise folder. Add `Third sentence.` and use `Ctrl+S`.

**Check:** after reopening the file, it has four lines and the last says `Third sentence.`.

**Safe return:** change one word and press `Ctrl+Z`; the saved file remains a separate exercise file. Do not save over a working document.
