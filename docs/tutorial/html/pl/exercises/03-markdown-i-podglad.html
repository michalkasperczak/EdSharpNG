Ćwiczenie 03 — Markdown i podgląd

Spis treści

  1. Kroki

Cel. Zapisać prosty Markdown i bezpiecznie wejść oraz wyjść z podglądu.

Kroki

Zapisz nowy plik jako spotkanie.md, a następnie wpisz:

# Spotkanie

- kawa
- notatki

[Strona projektu](https://example.invalid/edsharp)

Zapisz plik, naciśnij Escape, przeczytaj tekst podglądu, a potem ponownie naciśnij Escape.

Sprawdź: w edycji nadal widzisz dokładnie zapis Markdown. Podgląd można opuścić klawiszem Escape; nie edytujesz go jak strony WWW.

Bezpieczny powrót: jeśli zmienisz tekst po wyjściu z podglądu, Ctrl+Z cofa tę zmianę. Nie otwieraj linku do ćwiczenia — jest tylko przykładem składni.
