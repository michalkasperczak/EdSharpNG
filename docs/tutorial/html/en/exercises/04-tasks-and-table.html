Exercise 04 — tasks and table

Contents

  1. Steps
  2. Expected result
  3. Safe return
Target PL/EN menu DRAFT. Do this only in a new exercise file; it is not evidence of a GUI or NVDA test.

Goal. Create two tasks, toggle one, and insert a small table.

Steps

  1. In a new file type buy bread and reply.
  2. Select both lines and press Ctrl+Shift+F2.
  3. Put the caret on the first task, press Ctrl+Shift+X, then Alt+Shift+F2.
  4. Press Ctrl+Shift+T, provide two headings and two data rows, then confirm with Ctrl+Enter.

Expected result

Both lines are a task list; the first is - [x] and the second is - [ ]. In the DRAFT, Review > Tasks changes between Mark as Done and Mark as Not Done, while help/the palette use Toggle Task Completion. The outcome speech is Done or Not Done. A Markdown table is in the current document; its target location is Insert > Insert Table….

Safe return

Ctrl+Z reverses the last operation only in this exercise file.
